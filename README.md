# 시간이 돈이다

출근·퇴근·헬스장 QR을 스캔해 시간을 돈으로 기록하는 오프라인 Android 앱입니다.

- 출근 QR: 기본 09:00 마감
- 퇴근 QR: 기본 20:00 마감
- 출근/퇴근 실패: 각각 기본 10,000원씩 `잃은 돈`으로 기록
- 헬스장 QR: 하루 한 번, 기본 10,000원을 `번 돈`으로 기록
- 월요일부터 일요일까지 매일 체크
- 휴가·출장 같은 날은 출근/퇴근을 골라 사유와 함께 예외 처리
- 출근 성공률과 퇴근 성공률을 별도 집계
- 매달 마지막 날 `잃은 돈`과 `번 돈`을 별도로 알림
- 잃은 돈은 월말 기부 금액으로 안내

모든 설정과 기록은 서버 없이 기기 안에만 저장됩니다.

## 바로 설치

[time-is-money.apk](./time-is-money.apk)를 Android 기기로 옮겨 설치하세요. 처음 설치할 때 브라우저나 파일 앱의 `알 수 없는 앱 설치` 허용이 필요할 수 있습니다.

앱에서 `QR 보기`를 누르면 서로 다른 출근·퇴근·헬스장 QR을 볼 수 있습니다. 인쇄용 PNG는 [`qr-codes`](./qr-codes) 폴더에도 들어 있습니다.

세 PNG를 각각 장소에 출력해 붙인 뒤 앱의 `QR 스캔하기`로 읽습니다. 스캐너는 APK에 내장되어 있으며 첫 사용 때 카메라 권한만 허용하면 됩니다.

## 개발 및 빌드

```powershell
npm.cmd install
npm.cmd test
npm.cmd run android:apk
```

Android 네이티브 프로젝트는 `android/`, 화면 코드는 `www/`에 있습니다.
